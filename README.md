The Professor Tracker System (PST) is a professor schedule tracker made for students and professor.PST allows students to view a professor’s schedule without the need to go to the faculty in person. The system allows students to view, search, and filter out professors by name or department. Professors, on the other hand, can log in to the system, edit their status, and add, edit, and delete their schedule.

This system used the following technologies:
Frontend: HTML, CSS, JavaScript
Backend: Node.js
Database: MongoDB (NoSQL)
Containerization: Docker
